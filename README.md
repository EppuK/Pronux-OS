# Pronux-OS
Linux distribution based on Gentoo, meant for professionals

Pronux OS is a Gentoo-based Linux distribution (for now), intended for professional users only. It's primarily aimed for those, who need "wrong" type of software to function. 



### If you are general user, who's not long time Linux user, or self-proclaimed Linux "pro", please leave. Amateurs are not welcome





## Goals of the Distro

- Minimal to no corporate-based software (e.g., no Wayland or NVIDIA drivers by default)
- No cucked licenses (MIT, BSD for Apache Licenses)
- Stability (not for the amateurs though)
- Being lightweight as possible.
- Being restrictive.
- Avoid general users!



## Software that is being used by Pronux OS

- XLibre (for now)
- Modified version of DWM (for now)
- Qutebrowser (for now)
- Pure ALSA for audio.
